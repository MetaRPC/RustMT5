# MT5Service — 4. Market Depth (DOM)

> Subscribe → read → release the order book, each by a plain `&str` symbol.

**Layer:** MID over [`MT5Account` Market Depth](../MT5Account/4.%20Market_Depth/Market_Depth.Overview.md). Defined in [`src/mt5/service.rs`](https://github.com/MetaRPC/RustMT5/blob/main/src/mt5/service.rs).

---

## The 3 methods

| Method | Returns | Tier | Delegates to |
|--------|---------|------|--------------|
| `subscribe_market_depth(symbol)` | `MarketBookAddData` | 🔵 friendly args | `market_book_add(..)` |
| `market_depth(symbol)` | `MarketBookGetData` | 🔵 friendly args | `market_book_get(..)` |
| `unsubscribe_market_depth(symbol)` | `MarketBookReleaseData` | 🔵 friendly args | `market_book_release(..)` |

**Where the value is:** friendlier names (`subscribe`/`unsubscribe`) and a `&str` symbol instead of building each `MarketBook*Request`. The lifecycle is the same as the low level: **subscribe once → read repeatedly → release**.

---

## Signatures

```rust
pub async fn subscribe_market_depth(&self, symbol: &str) -> Result<pb::MarketBookAddData, MT5Error>
pub async fn market_depth(&self, symbol: &str) -> Result<pb::MarketBookGetData, MT5Error>
pub async fn unsubscribe_market_depth(&self, symbol: &str) -> Result<pb::MarketBookReleaseData, MT5Error>
```

* `MarketBookAddData.opened_successfully: bool`
* `MarketBookReleaseData.closed_successfully: bool`
* `MarketBookGetData.mql_book_infos: Vec<MrpcMqlBookInfo>` — each level has `r#type` (`BookType`: `Sell`=0, `Buy`=1, `SellMarket`=2, `BuyMarket`=3), `price`, `volume`, `volume_real`. Full detail: low-level [market_book_get](../MT5Account/4.%20Market_Depth/market_book_get.md).

## 🔗 Usage Examples

### 1) Full lifecycle

```rust
let ok = service.subscribe_market_depth("EURUSD").await?.opened_successfully;
if ok {
    let book = service.market_depth("EURUSD").await?;
    println!("{} levels", book.mql_book_infos.len());
    service.unsubscribe_market_depth("EURUSD").await?;
}
```

### 2) Best bid / best ask

```rust
use metarpc_mt5::proto::mt5_term_api::BookType;

service.subscribe_market_depth("EURUSD").await?;
let book = service.market_depth("EURUSD").await?;
let best_bid = book.mql_book_infos.iter()
    .filter(|l| matches!(BookType::try_from(l.r#type), Ok(BookType::Buy)))
    .map(|l| l.price).fold(f64::MIN, f64::max);
let best_ask = book.mql_book_infos.iter()
    .filter(|l| matches!(BookType::try_from(l.r#type), Ok(BookType::Sell)))
    .map(|l| l.price).fold(f64::MAX, f64::min);
println!("book spread {:.5}", best_ask - best_bid);
service.unsubscribe_market_depth("EURUSD").await?;
```

### 3) Depth per side

```rust
use metarpc_mt5::proto::mt5_term_api::BookType;

let book = service.market_depth("EURUSD").await?;
let (bid, ask) = book.mql_book_infos.iter().fold((0i64, 0i64), |(b, a), l| match BookType::try_from(l.r#type) {
    Ok(BookType::Buy) => (b + l.volume, a),
    Ok(BookType::Sell) => (b, a + l.volume),
    _ => (b, a),
});
println!("bid depth {bid}, ask depth {ask}");
```

---

## ⚠️ Pitfalls

* **Subscribe first.** `market_depth` returns nothing useful without a prior `subscribe_market_depth`.
* **Always release.** Balance every subscribe with an unsubscribe.
* **FX often has no DOM** — `opened_successfully` may be `false`.
