# MT5Service — 2. Symbol Information

> Discovery, quotes, properties, sessions and bulk params — with `&str` symbols, typed property enums, and scalar returns where it makes sense.

**Layer:** MID over [`MT5Account` Symbol Information](../MT5Account/2.%20Symbol_Information/Symbol_Information.Overview.md). Defined in [`src/mt5/service.rs`](https://github.com/MetaRPC/RustMT5/blob/main/src/mt5/service.rs).

**Where the value is:** the getters unwrap to a scalar (`i32`/`String`/`bool`/`f64`/`i64`), and every method takes a `&str` symbol + typed property/`DayOfWeek`/`EnumOrderType` enum so you never build a `…Request` or cast to `i32`.

## Signatures

```rust
pub async fn symbols_total(&self, selected_only: bool) -> Result<i32, MT5Error>
pub async fn symbol_exist(&self, name: &str) -> Result<pb::SymbolExistData, MT5Error>
pub async fn symbol_name(&self, index: i32, selected_only: bool) -> Result<String, MT5Error>
pub async fn symbol_select(&self, symbol: &str, select: bool) -> Result<bool, MT5Error>
pub async fn symbol_is_synchronized(&self, symbol: &str) -> Result<bool, MT5Error>

pub async fn symbol_double(&self, symbol: &str, property: pb::SymbolInfoDoubleProperty) -> Result<f64, MT5Error>
pub async fn symbol_integer(&self, symbol: &str, property: pb::SymbolInfoIntegerProperty) -> Result<i64, MT5Error>
pub async fn symbol_string(&self, symbol: &str, property: pb::SymbolInfoStringProperty) -> Result<String, MT5Error>

pub async fn symbol_margin_rate(&self, symbol: &str, order_type: pb::EnumOrderType) -> Result<pb::SymbolInfoMarginRateData, MT5Error>
pub async fn symbol_tick(&self, symbol: &str) -> Result<pb::MrpcMqlTick, MT5Error>
pub async fn symbol_session_quote(&self, symbol: &str, day: pb::DayOfWeek, session_index: u32) -> Result<pb::SymbolInfoSessionQuoteData, MT5Error>
pub async fn symbol_session_trade(&self, symbol: &str, day: pb::DayOfWeek, session_index: u32) -> Result<pb::SymbolInfoSessionTradeData, MT5Error>
pub async fn symbol_params_many(&self, symbol_name: Option<String>, page_number: Option<i32>, items_per_page: Option<i32>) -> Result<pb::SymbolParamsManyData, MT5Error>
```

> `symbol_params_many` always passes `sort_type: None` to the low layer. If you need sorting, call `MT5Account::symbol_params_many` directly via `service.account()`.

Property enums come straight from the low-level pages — [symbol_info_double](../MT5Account/2.%20Symbol_Information/symbol_info_double.md), [integer](../MT5Account/2.%20Symbol_Information/symbol_info_integer.md), [string](../MT5Account/2.%20Symbol_Information/symbol_info_string.md). `DayOfWeek`: `Sunday`=0 … `Saturday`=6.

## 🔗 Usage Examples

### 1) Exists → select → quote

```rust
use metarpc_mt5::proto::mt5_term_api as pb;

if service.symbol_exist("EURUSD").await?.exists {
    service.symbol_select("EURUSD", true).await?;           // bool
    let t = service.symbol_tick("EURUSD").await?;            // MrpcMqlTick
    println!("bid/ask {:.5}/{:.5}", t.bid, t.ask);
}
```

### 2) Properties as scalars

```rust
use metarpc_mt5::proto::mt5_term_api::{SymbolInfoDoubleProperty as D, SymbolInfoIntegerProperty as I};

let point  = service.symbol_double("EURUSD", D::SymbolPoint).await?;   // f64
let digits = service.symbol_integer("EURUSD", I::SymbolDigits).await?; // i64
println!("point {point}, digits {digits}");
```

### 3) Full spec of one symbol

```rust
let data = service.symbol_params_many(Some("EURUSD".into()), None, None).await?;
if let Some(p) = data.symbol_infos.first() {
    println!("{}: contract {}, bid {:.5}", p.name, p.point, p.bid);
}
```

### 4) Is the market open today?

```rust
use metarpc_mt5::proto::mt5_term_api::DayOfWeek as Dow;

let s = service.symbol_session_trade("EURUSD", Dow::Monday, 0).await?;
println!("trade session present: {}", s.from.is_some());
```

## ⚠️ Pitfalls

* **Typed enums, `&str` symbols** — no manual `…Request` or `as i32`.
* **`symbol_params_many` has no sort here** — use the low layer if you need it.
* **Select before quoting/history** — same rule as the low level.
* **`symbol_exist` is a pass-through** — returns `SymbolExistData` (`.exists`, `.is_custom`), not a bare bool.
