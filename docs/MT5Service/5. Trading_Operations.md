# MT5Service — 5. Trading Operations

> Send/modify/close/check orders (raw requests) + margin/profit calculators (friendly args).

**Layer:** MID over [`MT5Account` Trading Operations](../MT5Account/5.%20Trading_Operations/Trading_Operations.Overview.md). Defined in [`src/mt5/service.rs`](https://github.com/MetaRPC/RustMT5/blob/main/src/mt5/service.rs).

---

## The 6 methods

| Method | Returns | Tier | Delegates to |
|--------|---------|------|--------------|
| `place_order(request)` | `OrderSendData` | ⚪ pass-through | `order_send(..)` |
| `modify_order(request)` | `OrderModifyData` | ⚪ pass-through | `order_modify(..)` |
| `close_order(request)` | `OrderCloseData` | ⚪ pass-through | `order_close(..)` |
| `check_order(request)` | `OrderCheckData` | ⚪ pass-through | `order_check(..)` |
| `calculate_margin(symbol, order_type, volume, open_price)` | `OrderCalcMarginData` | 🔵 friendly args | `order_calc_margin(..)` |
| `calculate_profit(symbol, order_type, volume, open_price, close_price)` | `OrderCalcProfitData` | 🔵 friendly args | `order_calc_profit(..)` |

**Design note:** order **construction** (symbol/side/volume → `OrderSendRequest`, pip-based SL/TP, risk sizing) is deliberately **not** here — that's [`MT5Sugar`](../MT5Sugar/MT5Sugar.Master.Overview.md)'s job. At this layer `place_order`/`modify_order`/`close_order`/`check_order` take the protobuf request directly (mirroring the Python facade), so they're pass-throughs. The two **calculators** do add friendly args: `&str` symbol + typed `EnumOrderTypeTf`, returning the `…Data`.

---

## Signatures

```rust
pub async fn place_order(&self, request: pb::OrderSendRequest) -> Result<pb::OrderSendData, MT5Error>
pub async fn modify_order(&self, request: pb::OrderModifyRequest) -> Result<pb::OrderModifyData, MT5Error>
pub async fn close_order(&self, request: pb::OrderCloseRequest) -> Result<pb::OrderCloseData, MT5Error>
pub async fn check_order(&self, request: pb::OrderCheckRequest) -> Result<pb::OrderCheckData, MT5Error>

pub async fn calculate_margin(
    &self, symbol: &str, order_type: pb::EnumOrderTypeTf, volume: f64, open_price: f64,
) -> Result<pb::OrderCalcMarginData, MT5Error>

pub async fn calculate_profit(
    &self, symbol: &str, order_type: pb::EnumOrderTypeTf, volume: f64, open_price: f64, close_price: f64,
) -> Result<pb::OrderCalcProfitData, MT5Error>
```

* **Return code:** `OrderSendData.returned_code` / `OrderCloseData.returned_code` — **`10009` = success**. See [Return Codes](../All_Guides/RETURN_CODES_REFERENCE.md).
* `EnumOrderTypeTf`: `OrderTypeTfBuy`=0, `OrderTypeTfSell`=1, `OrderTypeTfBuyLimit`=2, …
* Request/field tables: low-level [order_send](../MT5Account/5.%20Trading_Operations/order_send.md), [order_modify](../MT5Account/5.%20Trading_Operations/order_modify.md), [order_close](../MT5Account/5.%20Trading_Operations/order_close.md), [order_check](../MT5Account/5.%20Trading_Operations/order_check.md).

## 🔗 Usage Examples

### 1) Check → place (the safe flow)

```rust
use metarpc_mt5::proto::mt5_term_api as pb;
use pb::Tmt5EnumOrderType as OT;

// validate
let check = service.check_order(pb::OrderCheckRequest {
    mql_trade_request: Some(pb::MrpcMqlTradeRequest { symbol: "EURUSD".into(), volume: 0.10, price: 1.085, ..Default::default() }),
}).await?;
let ok = check.mql_trade_check_result.map(|r| r.returned_code == 10009).unwrap_or(false);

if ok {
    let res = service.place_order(pb::OrderSendRequest {
        symbol: "EURUSD".into(), operation: OT::Tmt5OrderTypeBuy as i32, volume: 0.10,
        price: None, slippage: Some(20), stop_loss: None, take_profit: None,
        comment: Some("svc".into()), expert_id: Some(1), stop_limit_price: None,
        expiration_time_type: None, expiration_time: None, quotes_wait_ms: None,
    }).await?;
    println!("send code {}", res.returned_code);
}
```

### 2) Margin for a would-be order

```rust
use metarpc_mt5::proto::mt5_term_api::EnumOrderTypeTf as TF;

let price = service.symbol_tick("EURUSD").await?.ask;
let m = service.calculate_margin("EURUSD", TF::OrderTypeTfBuy, 1.0, price).await?.margin;
println!("margin for 1.0 lot: {m:.2}");
```

### 3) Profit of a 50-pip move

```rust
use metarpc_mt5::proto::mt5_term_api::EnumOrderTypeTf as TF;

let open = 1.08500;
let p = service.calculate_profit("EURUSD", TF::OrderTypeTfBuy, 0.10, open, open + 0.0050).await?.profit;
println!("profit: {p:+.2}");
```

## ⚠️ Pitfalls

* **Execution methods take raw requests.** Build the `OrderSendRequest`/etc. yourself here, or step up to `MT5Sugar` for symbol/side/pip helpers.
* **Check `returned_code == 10009`.**
* **Calculators use `EnumOrderTypeTf`** (the `…Tf` enum), not `EnumOrderType`.
