# MT5Service — 6. Streaming Methods

> Real-time streams with friendlier arguments (`Vec<String>` symbols, plain timer/flag params). Same item payloads as the low level.

**Layer:** MID over [`MT5Account` Streaming](../MT5Account/6.%20Streaming_Methods/Streaming_Methods.Overview.md). Defined in [`src/mt5/service.rs`](https://github.com/MetaRPC/RustMT5/blob/main/src/mt5/service.rs).

---

## The 5 streams

| Method | Item | Tier | Delegates to |
|--------|------|------|--------------|
| `stream_ticks(symbols)` | `OnSymbolTickData` | 🔵 friendly args | `on_symbol_tick(..)` |
| `stream_trade_updates()` | `OnTradeData` | ⚪ pass-through | `on_trade(default)` |
| `stream_position_profits(timer_period_ms, ignore_empty)` | `OnPositionProfitData` | 🔵 friendly args | `on_position_profit(..)` |
| `stream_opened_tickets(timer_period_ms)` | `OnPositionsAndPendingOrdersTicketsData` | 🔵 friendly args | `on_positions_and_pending_orders_tickets(..)` |
| `stream_transactions()` | `OnTradeTransactionData` | ⚪ pass-through | `on_trade_transaction(default)` |

**Where the value is:** you pass a `Vec<String>` / a timer in ms / a bool flag instead of constructing the `On*Request`. Each returns the same `Result<impl Stream<Item = Result<…Data, MT5Error>>, MT5Error>` as the low level — the **outer** `Result` is "subscription opened", then you iterate.

## 🔗 Usage Examples

### 1) Live ticks

```rust
use tokio_stream::StreamExt;

let mut s = service.stream_ticks(vec!["EURUSD".into(), "GBPUSD".into()]).await?;
while let Some(item) = s.next().await {
    match item {
        Ok(d) => if let Some(t) = d.symbol_tick { println!("{} {:.5}/{:.5}", t.symbol, t.bid, t.ask); },
        Err(e) => { eprintln!("stream error: {e}"); break; }
    }
}
```

### 2) Live total floating P/L (every second, quiet when idle)

```rust
use tokio_stream::StreamExt;
use std::collections::HashMap;

let mut s = service.stream_position_profits(1000, true).await?;
let mut book: HashMap<i64, f64> = HashMap::new();
while let Some(Ok(d)) = s.next().await {
    for p in d.new_positions.iter().chain(d.updated_positions.iter()) { book.insert(p.ticket, p.profit); }
    for p in &d.deleted_positions { book.remove(&p.ticket); }
    println!("floating {:+.2} ({} pos)", book.values().sum::<f64>(), book.len());
}
```

### 3) React to trade events

```rust
use tokio_stream::StreamExt;

let mut s = service.stream_trade_updates().await?;
while let Some(Ok(d)) = s.next().await {
    if let Some(a) = d.account_info { println!("event {} | equity {:.2}", d.r#type, a.equity); }
}
```

## ⚠️ Pitfalls

* **`use tokio_stream::StreamExt;`** to get `.next()`.
* **Two `Result`s:** outer = opened, inner (per item) = frame-or-error.
* **Timer streams push on a clock** (`stream_position_profits`, `stream_opened_tickets`); event streams push on change.
* **Dropping the stream unsubscribes.**
